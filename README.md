# Basket Digital – Applied Web Project Part 2

COS10026 Web Technology Project | Group G05

## About the project

Basket Digital is a recruitment website that we originally developed for Project Part 1. For Part 2, we improved the website by using PHP and MySQL to make it dynamic and database-driven.

Applicants can browse available jobs, search for specific roles and submit an expression of interest. We also created a management page where the HR manager can view and manage applications.

## How to run the website

1. Download the repository.
2. Place the project2 folder inside the XAMPP htdocs directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open http://localhost/project2/index.php in your browser.
5. Open the Jobs page to initialise the database if it has not already been created.

The database setup file is included as project2/database.sql. The local database connection uses the settings in settings.php.
